# 18-filterable-product-catlog

A responsive product catalog web application with advanced filtering, sorting, and real-time search functionality built using HTML, CSS, and JavaScript.


 Features

 Product listing display
 Real-time search functionality
 Filter products by:
   Category
   Price range
   Rating
Sort products by:
   Price Low to High
   Price High to Low
   Rating
   Name (A-Z)
 Responsive design
 Dynamic UI updates
 Uses JavaScript array methods


 Technologies Used

 HTML5
 CSS3
 JavaScript (ES6)
